# 仙女皇家 一級獲利

給一級、皇家夥伴使用的獲利手帳。仙女團隊專屬資源｜巧穎開發

網站內容已用通關密碼加密。請不要把密碼寫在這個專案的任何檔案裡。

## 上傳到 GitHub Pages
1. 在 GitHub 建一個新專案（名稱取不容易猜的）
2. 把這個資料夾裡的所有檔案上傳（index.html、manifest.json 和所有 icon 圖檔）
3. 到 Settings → Pages，Branch 選 main、資料夾選 / (root)，按 Save
4. 等一兩分鐘就會出現網址，網址和密碼只傳給一級和皇家夥伴

## 資料說明
每位夥伴的紀錄只存在自己手機的瀏覽器裡，別人看不到。換手機前請到「設定」下載備份檔，再到新手機匯入。
