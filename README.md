# 仙女皇家 一級獲利

給一級、皇家夥伴使用的獲利手帳。仙女團隊專屬資源｜巧穎開發

## 上傳到 GitHub Pages
1. 在 GitHub 建一個新專案（名稱取不容易猜的，例如 fr-9k27-journal）
2. 把這個資料夾裡的所有檔案上傳（index.html、manifest.json 和所有 icon 圖檔；Logo 已經內建在 index.html 裡）
3. 到 Settings → Pages，Branch 選 main、資料夾選 / (root)，按 Save
4. 等一兩分鐘，就會出現網址，只傳給一級和皇家夥伴

## 要改成本價
打開 index.html，找到「產品與成本」那一段，L1 是一級成本、ROYAL 是皇家成本、retail 是建議售價。

## 資料說明
每位夥伴的紀錄只存在自己手機的瀏覽器裡，別人看不到。換手機前請到「設定」下載備份檔，再到新手機匯入。
